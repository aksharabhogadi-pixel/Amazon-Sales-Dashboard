Amazon Sales Dashboard 

Project Overview

The Amazon Sales Dashboard is an Excel-based data analytics project designed to analyse sales performance and provide meaningful business insights through interactive visualisations.

The dashboard helps understand sales trends, order performance, payment methods and overall business performance.

Objectives

Analyse overall sales performance.
 Track order status, including Delivered, Returned and Cancelled orders.
 Identify top-performing products.
 Understand payment method distribution.
 Monitor key performance indicators (KPIs).
 Present business insights through charts and visual dashboards.

Tools & Technologies Used

Microsoft Excel
 Pivot Tables
 Pivot Charts
 Data Cleaning
 Data Analysis
 Excel Dashboard Visualisation

Dashboard Features

 Sales Analysis: Understand overall sales performance.
 Order Performance: Analyse delivered, returned and cancelled orders.
 Payment Analysis: Compare sales across different payment methods.
 Top 10 Sales: Identify top-performing products.
 KPI Analysis: Display important business performance metrics.

Key Insights

The dashboard helps identify:

Overall sales performance and trends.
 Distribution of order statuses.
 Popular payment methods.
 Top-performing products.
 Important areas for improving business performance.

Project Files

"Amazon_Sales_Dashboard.xlsx" – Main Excel dashboard.

Project Outcome

This project demonstrates practical skills in Excel-based data cleaning, data analysis, Pivot Tables, data visualisation and dashboard creation.

It provides a clear overview of Amazon sales performance and supports data-driven business decisions.
